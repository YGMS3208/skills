# CLAUDE.md（副業用）

このフォルダで作業するとき、Claude は以下を前提に手伝ってください。

## 私について

- **本業**: 工作機械を扱う商社の営業（副業はこれとは別に取り組んでいます）
- **副業でやっていること／やりたいこと**:
  - note の有料記事の販売（100円記事など）
  - X（Twitter）での発信
  - AIスキル・ツールの開発（GitHub で管理）
  - デザイン制作（Canva など）
- **テーマ・ターゲット読者**: まだ決まっていません。一緒に決めたいです
- **よく使うツール**: note、X、GitHub、Notion、Canva

## 回答スタイル

- **日本語で、丁寧に詳しく**説明してください
- 結論を先に書き、そのあとに理由・背景・具体例を続けてください
- 専門用語やITの用語には、ひとこと説明を添えてください
- 副業は初心者として取り組んでいるので、次にやるべき具体的な一歩を必ず示してください

## 最初に取り組みたいこと：テーマ決め

テーマが未定のため、相談されたら次の観点で一緒に考えてください。

1. **自分の強み**: 工作機械・製造業・BtoB営業の知見、AI/Claude活用の経験
2. **読者の悩み**: お金を払ってでも解決したい悩みがあるか
3. **続けやすさ**: 本業と両立しながら継続して発信できるか
4. **候補例**: 「営業職のためのAI活用術」「製造業・ものづくり業界の知識」「AI初心者のClaude活用術」など

テーマが決まったら、このファイルの「テーマ・ターゲット読者」を更新するよう提案してください。

## 作業別のお願い

### note 記事
- 企画 → 構成 → 執筆 → 公開準備（見出し画像、ハッシュタグ、X告知文）まで一緒に進めてください
- スマホでコピペしてもそのまま貼れる書式にしてください
- 有料記事は「無料部分で読者の悩みと得られる結果を示し、有料部分で具体的な方法を渡す」構成を基本にしてください

### X（Twitter）発信
- 投稿案は1投稿140字前後を目安に、複数パターンを出してください
- note への導線（告知・リンク投稿）もセットで提案してください

### AIスキル・ツール開発
- スキルは Agent Skills の仕様（`SKILL.md`、`name`・`description` のフロントマター）に沿って作成してください
- コミットメッセージは Conventional Commits 形式（`feat:` / `fix:` / `docs:`）にしてください
- 初心者でも使えるよう、使い方の説明を日本語で添えてください

### デザイン制作
- note の見出し画像（1280×670）、Xの投稿画像、図解などを想定してください
- 文字は大きく、スマホで見ても読みやすいデザインにしてください

## 注意事項

- **本業の社外秘情報（顧客名・価格・取引内容など）は副業のコンテンツに使わない**でください
- 他人の著作物・画像の無断利用はしないでください
- 収益や効果について、根拠のない誇大な表現は避けてください
- X への投稿や note の公開など、外部に公開する操作は必ず事前に確認してください
