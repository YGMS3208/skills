# profiles（個人用 CLAUDE.md）

仕事用と副業用で Claude への指示を分けるための CLAUDE.md です。

| フォルダ | 用途 |
|---|---|
| `work/` | 本業（工作機械商社の営業） |
| `side-business/` | 副業（note・X発信・AIスキル開発・デザイン制作） |

## 使い方

作業用フォルダに、目的に合う `CLAUDE.md` をコピーして使います。

```bash
cp profiles/work/CLAUDE.md ~/仕事/CLAUDE.md
cp profiles/side-business/CLAUDE.md ~/副業/CLAUDE.md
```

Claude Code は、作業しているフォルダの `CLAUDE.md` を自動で読み込みます。
